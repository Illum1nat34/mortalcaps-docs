# Продвижение Mortal Caps: общий список

Страница: https://illum1nat34.github.io/mortalcaps-docs/promo/

- `data.csv` — одна строка на канал или блогера. Править колонки «Статус», «Дата», «Кто», «Комментарий», прошлые записи — в «Историю» через `‖`.
  Статусы: Не писали, Написали, Ответили, Назвали цену, Договорились, Куплено, Отказались, Пока не пишем, Ранний ключ.
- `plan.md` — план закупки, `answers.md` — что ответили.
- После «Commit changes» страница обновляется примерно через минуту.
